# NL-OS — Nathan Lyons interactive CV

Terminal-style, Cyberpunk-HUD CV. Live at https://natkiio.github.io

Single self-contained `index.html`. All CV content lives in the `CV = {...}` object at the top of the script.
Type `help` on the page for commands, `sql` to query the CV as a SQLite database (sql.js), `git log` for live commits, or `print` for a clean PDF.
